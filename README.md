# Rooms Gaming Cafe — تحويل الموقع إلى برنامج exe

## طريقة من غير جهاز كمبيوتر أو Termux (الأسهل من الموبايل)
المشروع فيه ملف جاهز (`.github/workflows/build.yml`) بيخلي GitHub يبني الـ exe لك
على سيرفراتهم مجاناً، وانت بس ترفع الملفات من متصفح الموبايل وتنزل الـ exe الجاهز.

### الخطوات:
1. اعمل حساب مجاني على github.com (لو معندكش)
2. اعمل Repository جديد (New Repository) — سيبه Public أو Private، مفيش فرق
3. من صفحة الـ Repository، دوس "Add file" → "Upload files"
4. ارفع كل الملفات والفولدرات اللي جوه الزip ده (بما فيها فولدر .github لازم يترفع زي ما هو)
5. دوس "Commit changes" — ده هيشغّل عملية البناء أوتوماتيك
6. روح لتبويب "Actions" فوق في صفحة الـ Repository
7. هتلاقي عملية شغالة (دايرة صفراء بتلف) — استنى لحد ما تخلص وتبقى علامة ✅ خضرا (بتاخد 3-5 دقايق)
8. دوس على اسم العملية، وهتلاقي تحت في "Artifacts" ملف اسمه rooms-gaming-cafe-windows
9. نزّله — هيكون فيه ملف الـ exe جاهز للتشغيل على أي جهاز ويندوز

كل ده ينفع تعمله من متصفح الموبايل عادي، من غير أي تثبيت برامج.

## ملاحظة مهمة
البرنامج ده **بيفضل محتاج إنترنت وهو شغال**، لأنه بيتصل بـ Supabase (قاعدة البيانات والصور)
وبيحمّل مكتبة Supabase وخط الكتابة من الإنترنت. الـ exe مجرد "غلاف" (نافذة) حوالين نفس الموقع،
مش نسخة أوفلاين منه.

## طريقة تانية (لو عندك جهاز ويندوز)

### المتطلبات
- تثبيت Node.js: https://nodejs.org

### الخطوات
1. فك ضغط الملف
2. افتح Terminal / CMD جوه فولدر المشروع اللي فيه package.json
3. نفّذ:
   ```
   npm install
   ```
   (الخطوة دي بتنزل Electron وElectron Builder، محتاجة إنترنت وممكن تاخد كام دقيقة)

4. لتجربة البرنامج قبل ما تعمل exe:
   ```
   npm start
   ```

5. لعمل ملف exe فعلي (installer + نسخة portable):
   ```
   npm run dist
   ```
   هتلاقي الملفات جاهزة في فولدر: `dist/`
   - `Rooms Gaming Cafe Setup x.x.x.exe` → برنامج تثبيت عادي
   - `Rooms Gaming Cafe x.x.x.exe` (portable) → يشتغل مباشرة من غير تثبيت

## بديل أسرع (بدون مشروع كامل، على جهاز فيه Node.js)
```
npx nativefier "المسار الكامل لملف index.html" --name "Rooms Gaming Cafe" --platform windows
```

## تعديل شعار البرنامج (اختياري)
حط ملف icon.ico (256x256) جوه الفولدر وضيف السطر ده تحت "win" في package.json:
```
"icon": "icon.ico"
```
